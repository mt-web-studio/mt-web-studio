Services

対応可能な業務

個人・小規模事業者様のWebサイトを中心に、以下のようなご依頼に対応しています。

  • Webサイト制作

    小規模なコーポレートサイトや店舗サイトなど、数ページ構成のサイト制作に対応します。

  • HTML / CSSコーディング

    デザインカンプやワイヤーフレームをもとにしたコーディングに対応します。

  • レスポンシブ対応

    スマートフォン・タブレット・PCでの表示崩れがないよう調整します。

  • Webサイトの軽微な修正

    テキストや画像の差し替え、レイアウトの微調整などに対応します。

  • JavaScriptによる簡単な機能追加

    フォーム入力チェックやメニュー開閉など、必要な範囲での機能追加に対応します。

  • LPコーディング

    1ページ完結型のランディングページのコーディングに対応します。

About

自己紹介

HTML / CSS / JavaScriptを中心に、Webサイトの制作・実装を学びながら実績を積んでいます。 このポートフォリオに掲載しているGreen Table・LUMINA HAIRも、架空の店舗を題材に一から設計・実装したものです。

ご相談内容やご予算に応じて、対応できる範囲を正直にお伝えした上で進めさせていただきます。 お気軽にお問い合わせください。
